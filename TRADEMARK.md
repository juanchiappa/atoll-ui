# Política de marca de Atoll

El código de Atoll es open source bajo Apache License 2.0. Esa licencia cubre el
código y **no** otorga derechos sobre la marca: "Atoll", "Atoll UI", el logo y la
identidad visual son de Juan Ignacio Chiappa.

## Permitido
- Mencionar el nombre de forma factual ("compatible con Atoll", "plugin para Atoll").
- Reseñas, notas de prensa, tutoriales y videos que hablen del proyecto.
- Capturas del software sin modificar para ilustrar esas menciones.
- Forks y redistribución del código, según la licencia, bajo otro nombre.

## No permitido sin permiso escrito
- Usar el nombre, el logo o el estilo visual en un producto, servicio o fork distribuido.
- Sugerir que un proyecto de terceros es oficial o está respaldado por Atoll.
- Usar la imagen del autor o del proyecto en publicidad o merchandising.

## Forks
Todo fork o versión modificada debe **cambiar el nombre y el logo** y dejar claro
que no es el proyecto oficial.

## Permisos
Para pedir autorización: abrir un issue en este repositorio.
